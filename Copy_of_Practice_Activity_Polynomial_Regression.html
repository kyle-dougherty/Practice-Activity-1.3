Let's use bill_length_mm to predict bill_depth_mm. Prepare your data and fit the following models on the entire dataset:

  • Simple linear regression (e.g. straight-line) model
  • Quadratic (degree 2 polynomial) model
  • Cubic (degree 3 polynomial) model
  • Degree 10 polynomial model

Make predictions for each model and plot your fitted models on the scatterplot.

In [5]:
import numpy as np
from sklearn.linear_model import LinearRegression
import matplotlib.pyplot as plt

x = penguins[["bill_length_mm"]].values
y = penguins["bill_depth_mm"].values

x_plot = np.linspace(x.min(), x.max(), 500).reshape(-1,1)

linear = LinearRegression().fit(x, y)
quad = LinearRegression().fit(np.column_stack([x, x**2]), y)
cubic = LinearRegression().fit(np.column_stack([x, x**2, x**3]), y)
deg10 = LinearRegression().fit(np.column_stack([x**i for i in range(1,11)]), y)

y_linear = linear.predict(x_plot)
y_quad = quad.predict(np.column_stack([x_plot, x_plot**2]))
y_cubic = cubic.predict(np.column_stack([x_plot, x_plot**2, x_plot**3]))
y_10 = deg10.predict(np.column_stack([x_plot**i for i in range(1,11)]))

plt.scatter(x, y)
plt.plot(x_plot, y_linear)
plt.plot(x_plot, y_quad)
plt.plot(x_plot, y_cubic)
plt.plot(x_plot, y_10)
plt.xlabel("bill_length_mm")
plt.ylabel("bill_depth_mm")
plt.show()
  • Are any of the models above underfitting the data? If so, which ones and how can you tell?
  • Are any of thhe models above overfitting the data? If so, which ones and how can you tell?
  • Which of the above models do you think fits the data best and why?

The linear model is underfitting because the relationship between bill length and bill depth is curved, and a straight line can’t capture that pattern. The degree-10 model is overfitting since it bends and wiggles a lot just to match the data. Overall, the quadratic or cubic model fits the data best because they follow the curved trend smoothly without the extreme overfitting seen in the high-degree model.
